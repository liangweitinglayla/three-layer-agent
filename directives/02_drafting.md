# 02 — Drafting

## Goal
Turn a chosen topic into a full draft in the writer's voice.

## Inputs
- The chosen candidate from directive 01
- `templates/style_guide.md` — **read this before writing a word**
- Source material with dates

## Steps
1. Read the style guide. Not skim — read.
2. Gather sources. Every factual claim needs one, with a date.
3. Draft to the length the argument needs.
4. Write the draft to `drafts/YYYY-MM-DD_slug.md`.
5. Hand it back for the writer's own pass. **The draft is raw material,
   never the published text.**

## Rules
- **The draft is not the piece.** The writer rewrites it. A system that
  publishes its own output produces text nobody stands behind, which is the
  one thing writing cannot afford.
- Follow the arc in the style guide. If the guide specifies a structure
  (personal → conceptual → systemic → global is one), climb it explicitly.
- Preserve the writer's constructions, including the ones a copy editor
  would flatten. A non-native register is a voice, not an error.
- Never invent a citation. If a source cannot be verified, mark it and say
  so. See directive 03.
- Respect the guardrails in the style guide without exception. Flag once,
  clearly, then defer — the writer decides what to publish about their own
  life.

## Known failure modes
- Drafts drift toward generic op-ed prose. The specific corrective is to
  re-read the style guide mid-draft, not at the end.
- Long analytical passages need short declarative sentences after them, or
  the reader stops tracking the argument.
